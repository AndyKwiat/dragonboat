# dragonboat

A monorepo: `godot-game/` (the game), `terrain-gen/` (the map painter),
`combat-prototype/`. Each has its own `CLAUDE.md` — read the one for the
directory you're working in.

## Git

- **Work on `main`. Do not create a branch unless the user asks for one.**
  If a change feels big enough to want isolation, say so and ask first —
  don't just branch.
- Commit messages are prefixed with the subproject: `godot-game: `,
  `terrain-gen: `.
- Only commit or push when the user asks.
